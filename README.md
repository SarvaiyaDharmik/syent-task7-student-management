
# Student Management System

A Python-based Student Management System with both CLI and Web Application support.

## Features

- Add Student
- View All Students
- Search Student
- Update Student Details
- Delete Student
- Student Records Management
- Shared JSON Database
- Responsive Web Dashboard
- Terminal and Browser Support

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Bootstrap 5
- JSON

## Installation

1. Clone the repository.

2. Install dependencies:

   pip install -r requirements.txt

## Run CLI Application

python main.py

## Run Web Application

python app.py

Open your browser:

http://127.0.0.1:3001

## Database

The application uses students.json for storing student records.

Both CLI and Web applications share the same database.
